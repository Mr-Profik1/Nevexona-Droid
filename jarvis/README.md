# Джарвис: помощник для Linux

Окно с чатом: вы пишете по-русски или по-английски, Джарвис отвечает текстом и голосом, выполняет команды, создаёт код и может управлять экраном (клики, ввод, клавиши). Терминальная версия: `jarvis-cli`.

Работает на Linux (Linux Mint 22.1+, Ubuntu 24.04+, Debian 12+), 64-бит, сеанс X11. С iPhone окно открыть нельзя: Джарвис работает на том ноутбуке, где он запущен.

## Быстрая настройка (5 шагов)

**1. Получите бесплатный ключ.** Откройте https://openrouter.ai/keys, войдите, нажмите «Create Key». Ключ начинается с `sk-or-v1-`. Никому его не показывайте, не вставляйте в чаты и в файлы репозитория.

**2. Откройте терминал:** `Ctrl+Alt+T`.

**3. Вставьте команду** (в терминале вставка: `Ctrl+Shift+V`), нажмите Enter, введите пароль от компьютера (при вводе он не виден) и дождитесь конца установки:
```
wget https://raw.githubusercontent.com/Mr-Profik1/Nevexona-Droid/main/jarvis/dist/jarvis_1.1.0_all.deb && sudo apt install ./jarvis_1.1.0_all.deb && jarvis --hotkey
```
Если `wget` не скачал файл: откройте `jarvis/dist/jarvis_1.1.0_all.deb` в репозитории на GitHub, скачайте вручную и выполните `sudo apt install ~/Загрузки/jarvis_1.1.0_all.deb`.

**4. Запустите:** команда `jarvis` или «Джарвис» в меню. Быстрый вызов: **Alt+7**.

**5. Вставьте ключ.** При первом запуске само откроется окно «Настройки». Всё уже заполнено, нужно только вставить ключ в поле и нажать «Сохранить». Вверху появится «ИИ: openrouter/free». Теперь пишите задачи.

Файлы создавать и конфиги править руками не нужно.

## Что можно писать
- `который час`, `открой firefox`, `громкость 50`: простые команды работают и без ИИ.
- `создай на рабочем столе файл hello.py, который печатает привет, и запусти`: ИИ пишет код и запускает.
- `открой браузер, найди сайт с VPN и скачай установщик`: ИИ смотрит на скриншот и кликает.
- `помощь` или `help`: список простых команд.

Каждая команда или действие на экране показывается карточкой с кнопками «Выполнить» и «Отмена». Кнопка «■» останавливает задачу.

## Защита «только для меня»
1. В окне нажмите «PIN» и задайте PIN. После этого при каждом запуске Джарвис его спрашивает; после 3 ошибок вход блокируется на 60 секунд. Хранится только хеш (PBKDF2).
2. Окно слушает только `127.0.0.1` (с других устройств недоступно), ссылка для входа одноразовая, запросы проверяются по Host, Origin и служебному заголовку.
3. Блокируйте экран, когда отходите: PIN не защищает от человека, уже севшего за вашу учётную запись.

## Модели
- **Чат:** `openrouter/free`, сервис сам выбирает любую свободную бесплатную модель.
- **Экран:** `nvidia/nemotron-3.5-super-vl:free`, бесплатная, понимает скриншоты. Джарвис переключается на неё сам, когда в запросе есть скриншот. Если меняете её, новая модель должна уметь изображения.
- Бесплатный лимит OpenRouter: около 20 запросов в минуту и 200 в день. При ошибке 429 подождите минуту.
- Другие сервисы с OpenAI-совместимым API (адрес вводится в «Настройки»): Groq `https://api.groq.com/openai/v1`, Gemini `https://generativelanguage.googleapis.com/v1beta/openai`.

## Если что-то не работает
| Проблема | Что делать |
|---|---|
| `wget` выдал 403 или 404 | Скачайте `.deb` вручную с GitHub (см. шаг 3) |
| `jarvis: команда не найдена` | Закройте терминал, откройте заново; или запустите через меню |
| Окно не открылось | Ссылка печатается в терминале: откройте её в браузере |
| Ошибка 401 | Ключ неверный: создайте новый на openrouter.ai/keys, вставьте в «Настройки» |
| Ошибка 402 или 429 | Лимит бесплатных запросов: подождите или смените модель |
| Не кликает и не печатает | Нужен X11: на входе в систему выберите сеанс Cinnamon (не Wayland); проверьте `xdotool` |
| Нет голоса | `sudo apt install espeak-ng`, включите кнопку «Голос» |
| Alt+7 не работает | Параметры → Клавиатура → Сочетания → добавьте команду `jarvis` |

## Управление и удаление
- Настройки и PIN: `~/.config/jarvis` (остаются при удалении пакета). Журнал действий: `~/.jarvis_log` (напечатанный текст не пишется).
- Обновить: повторите команду из шага 3 с новым номером версии.
- Удалить: `sudo apt remove jarvis`.

## Установка скриптом (вместо пакета)
```
curl -fsSL https://raw.githubusercontent.com/Mr-Profik1/Nevexona-Droid/main/jarvis/install_jarvis.sh | bash
```
Сразу с ключом (он сохранится только в `~/.config/jarvis/config`):
```
curl -fsSL https://raw.githubusercontent.com/Mr-Profik1/Nevexona-Droid/main/jarvis/install_jarvis.sh | JARVIS_API_KEY="ВАШ-КЛЮЧ" bash
```

Потом достаточно написать `rt`.

## Режим полного разрешения (для опытных)
Работает только при заданном PIN. ИИ выполняет команды и действия на экране без вопросов, всё пишется в `~/.jarvis_log`. Опасные команды (удаление, форматирование, перезагрузка) всё равно спрашивают, но фильтр простой, не полагайтесь на него.
```
sudo -v
JARVIS_AUTO=1 jarvis-cli
```

## Приватность
Хостинг не нужен, всё выполняется на вашем компьютере. Но запросы, вывод команд и скриншоты уходят облачному сервису, а у бесплатных моделей данные могут использоваться для обучения. Не просите ИИ показывать пароли и личные файлы. Полностью локальный вариант: Ollama (`http://localhost:11434/v1`, ключ `ollama`, для экрана нужна vision-модель).
