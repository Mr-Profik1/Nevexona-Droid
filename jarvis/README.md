# Джарвис: помощник для Linux

Вы пишете текстом, он отвечает текстом и голосом и выполняет задачи.

Два режима, переключаются сами:
- **С интернетом и настроенным ИИ:** ИИ сам решает, какие команды выполнить (скачать программу, открыть сайт, настроить что-то).
- **Без интернета или без ключа:** простые заданные команды (время, открыть программу, громкость, память и т.д.). Список: напишите `помощь`.

## Установка (одна команда)
```
curl -fsSL https://raw.githubusercontent.com/Mr-Profik1/Nevexona-Droid/main/jarvis/install_jarvis.sh | bash
```
Скрипт поставит голос (`espeak-ng`), команду `jarvis`, значок «Джарвис» на рабочем столе и в меню (двойной клик) и горячую клавишу **Alt+7**. Сочетание можно поменять: Параметры → Клавиатура → Сочетания → Пользовательские.

## Подключить ИИ
Нужен ключ от сервиса с OpenAI-совместимым API (ИИ работает в интернете). Адреса, например:
- OpenRouter: `https://openrouter.ai/api/v1`
- Groq: `https://api.groq.com/openai/v1`
- Gemini: `https://generativelanguage.googleapis.com/v1beta/openai`

Названия моделей меняются, берите актуальное на сайте сервиса. Доступность зависит от страны.
Для OpenRouter одной командой (подставьте свой ключ и имя модели с `:free` из openrouter.ai/models):
```
mkdir -p ~/.config/jarvis
printf 'JARVIS_BASE_URL="https://openrouter.ai/api/v1"\nJARVIS_API_KEY="ВАШ-КЛЮЧ"\nJARVIS_MODEL="ИМЯ-МОДЕЛИ"\n' > ~/.config/jarvis/config
chmod 600 ~/.config/jarvis/config
```
Или запустите Джарвиса и напишите `настройка`: он спросит адрес, ключ и модель и сохранит их в `~/.config/jarvis/config` (доступ только вам). Ключ никому не показывайте.

## Свои короткие команды (макросы)
```
макрос rt = setsid -f firefox
макрос r1 = nevexona-droid
макросы
удали макрос rt
```
Потом достаточно написать `rt` или `r1`.

## Режим полного разрешения
```
sudo -v
JARVIS_AUTO=1 jarvis
```
`sudo -v` один раз спросит пароль, после этого ИИ сможет вызывать sudo (например, `apt install`) несколько минут. ИИ выполняет команды без вопросов, все они записываются в `~/.jarvis_log`. Опасные команды (удаление, форматирование, перезагрузка и т.п.) даже в этом режиме спрашивают подтверждение. Без `JARVIS_AUTO=1` подтверждение нужно на каждую команду ИИ.

mkdir -p ~/.config/jarvis
cat > ~/.config/jarvis/config <<'EOF'
JARVIS_BASE_URL="https://openrouter.ai/api/v1"
JARVIS_API_KEY="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"
JARVIS_MODEL="ИМЯ-МОДЕЛИ"
EOF
chmod 600 ~/.config/jarvis/config


## Приватность
Хостинг не нужен, всё выполняется на вашем компьютере. Но при работе через облачный сервис ваши запросы и вывод команд отправляются этому сервису. Не просите ИИ выводить пароли и личные файлы.
Полностью локальный вариант: Ollama (https://ollama.com) с адресом `http://localhost:11434/v1`, ключом `ollama` и именем локальной модели. На 2 ГБ оперативки потянут только совсем маленькие модели, и они плохо справляются с такими задачами.
