# 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 Джарвис: помощник для Linux

Вы пишете текстом (по-русски или по-английски), он отвечает текстом и голосом, выполняет команды и может управлять экраном.

Два режима, переключаются сами:
- **С интернетом и настроенным ИИ:** ИИ сам решает, что сделать: команды bash, создание файлов с кодом, установка программ, действия на экране.
- **Без интернета или без ключа:** простые заданные команды (время, открыть программу, громкость, память и т.д.). Список: `помощь` или `help`.

Работает на Linux (Debian/Ubuntu/Mint) под X11. На iPhone и в Termux на телефоне управление экраном и открытие программ недоступны.

## Установка (одна команда)
```
curl -fsSL https://raw.githubusercontent.com/Mr-Profik1/Nevexona-Droid/main/jarvis/install_jarvis.sh | bash
```
Скрипт поставит `python3`, `curl`, голос (`espeak-ng`), для экрана `xdotool` и `scrot`, команду `jarvis`, значок и горячую клавишу **Alt+7** (Cinnamon). Запуск: `~/.local/bin/jarvis`.

Сразу с ключом ИИ (ключ не попадает в репозиторий, он сохраняется только в `~/.config/jarvis/config` с доступом для вас):
```
curl -fsSL https://raw.githubusercontent.com/Mr-Profik1/Nevexona-Droid/main/jarvis/install_jarvis.sh | JARVIS_API_KEY="ВАШ-КЛЮЧ" bash
```
Без `JARVIS_MODEL` берётся `nvidia/nemotron-3.5-super-vl:free` (бесплатная, умеет изображения).

## Подключить ИИ
Нужен ключ от сервиса с OpenAI-совместимым API. Адреса:
- OpenRouter: `https://openrouter.ai/api/v1`
- Groq: `https://api.groq.com/openai/v1`
- Gemini: `https://generativelanguage.googleapis.com/v1beta/openai`

Запустите Джарвиса и напишите `настройка`: он спросит адрес, ключ и модель. Бесплатные модели OpenRouter (с `:free`) есть на openrouter.ai/models; список меняется, лимит около 20 запросов в минуту. **Ключ никому не показывайте и не публикуйте.**

Для управления экраном нужна модель, которая умеет **изображения** (vision). Без неё остальное работает, а действия с экраном вернут ошибку.

## PIN
Команда `пин` задаёт или меняет PIN, `пин удалить` снимает. После этого Джарвис при каждом запуске спрашивает PIN; после 3 неверных попыток запуск блокируется на 60 секунд. В файле хранится только хеш (PBKDF2). PIN защищает запуск Джарвиса. Он не защищает от человека, у которого уже есть доступ к вашей учётной записи и терминалу: блокируйте экран.

## Управление экраном (только X11)
ИИ может сделать скриншот, кликнуть, напечатать текст, нажать клавиши и прокрутить. Нужны `xdotool` и `scrot` (или ImageMagick); в сеансе Wayland не работает. Каждое действие по умолчанию нужно подтверждать (`y`), можно ответить `a`: тогда до конца сессии подтверждения экрана не спрашиваются (опасный текст всё равно спросит). Скриншот отправляется ИИ-сервису, то есть через интернет. `Ctrl+C` останавливает текущую задачу. Все действия записываются в `~/.jarvis_log` (напечатанный текст не записывается).

## Свои короткие команды (макросы)
```
макрос rt = setsid -f firefox
макросы
удали макрос rt
```
Потом достаточно написать `rt`.

## Режим полного разрешения
Работает только если задан PIN.
```
sudo -v
JARVIS_AUTO=1 jarvis
```
`sudo -v` один раз спросит пароль, после этого ИИ сможет вызывать sudo несколько минут. ИИ выполняет команды и действия на экране без вопросов, все они пишутся в `~/.jarvis_log`. Опасные команды (удаление, форматирование, перезагрузка и т.п.) даже тут спрашивают подтверждение, но фильтр простой, не полагайтесь на него.

## Чего пока нет
Голосового ввода (говорить Джарвису нельзя, он только озвучивает ответы).

## Приватность
Хостинг не нужен, всё выполняется на вашем компьютере. Но запросы, вывод команд и скриншоты уходят облачному сервису, а у бесплатных моделей данные могут использоваться для обучения. Не просите ИИ показывать пароли и личные файлы.
Полностью локальный вариант: Ollama (https://ollama.com) с адресом `http://localhost:11434/v1`, ключом `ollama` и именем локальной модели (для экрана нужна vision-модель). На слабом железе локальные модели плохо справляются с такими задачами.
