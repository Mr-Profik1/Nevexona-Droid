# Простой помощник для Linux

Вы пишете текстом, он отвечает текстом и голосом и выполняет команды. Работает без интернета.

Запуск (скопируйте в терминал):
```
sudo apt install -y espeak-ng
curl -fsSL https://raw.githubusercontent.com/Mr-Profik1/Nevexona-Droid/main/jarvis/jarvis.py -o jarvis.py
python3 jarvis.py
```
Напишите `помощь`, чтобы увидеть список команд.
