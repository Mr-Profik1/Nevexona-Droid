# NEVEXONA Droid

Linux-приложение для запуска Android через Waydroid и ADB. **Проект в разработке.**

## Статус
Готово (ядро, покрыто тестами на подставных ответах):
- проверка совместимости системы, статусы Waydroid, ADB-менеджер, каталог F-Droid с проверкой SHA-256, настройки в SQLite.

Не готово: графический интерфейс, установщик, сборка пакетов.
Реальная работа с Waydroid/ADB ещё не проверялась на живой системе.
